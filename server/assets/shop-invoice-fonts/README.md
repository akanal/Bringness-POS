# Bundled preview fonts

Unmodified DejaVu Sans regular and bold, version 2.37, copied from the local
Debian font distribution. Original font notices and permission are in LICENSE.txt.
No Debian packaging scripts are copied. Do not remove the font licence from a
source package or deployment containing these files.

manifest.json records SHA-256 of each exact file and Unicode coverage from its
best cmap. It was generated with FontTools TTFont.getBestCmap by merging adjacent
codepoints into inclusive ranges. FontTools is a development inspection tool,
not a production dependency. The renderer checks file hashes before using that
coverage. Changing fonts requires regenerating/reviewing coverage and repeating
text/raster acceptance. This manifest is not an electronic signature or a defence
against an administrator able to rewrite the entire application.

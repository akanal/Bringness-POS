# Bringness green discovery design

The owner rejected the Amazon-like appearance and supplied a CHECK24 screenshot as a visual reference. The implementation uses an independent Bringness identity: emerald-to-white background gradient, rounded search/navigation chips, an asymmetric editorial card deck and a compact account entry strip. Existing category imagery is reused and remains explicitly illustrative, with no invented stock, discounts or availability.

The previous curved smile arrow is replaced across marketplace page headers/footers by a rising diagonal arrow in a small rounded mark. Account-area headers receive a restrained green gradient; POS/waiter and separate AI application branding are untouched. Existing cart, account, search, filter, comparison, draft and payment restrictions are preserved.

Native Chromium acceptance checks 1600/1280/768/390 viewport widths, overflow, page structure and identity while exercising the existing shop flows. Public homepage screenshots are retained as short-lived CI artifacts for visual review, before any sign-in or private fixture data is shown.

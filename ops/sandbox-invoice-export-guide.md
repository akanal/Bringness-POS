# Sandbox invoice exports

The issued invoice snapshot supports three company-scoped read-only representations: HTML, A4 print HTML, and Bringness sandbox JSON. The print view can be saved as PDF by a browser, but the server does not generate PDF files. The JSON export is not an EN16931 e-invoice.

Production readiness requires independently verified issuer details, accurate tax treatment, archival and corrections policy, and an appropriate structured e-invoice generator where required. No production rollout or payment testing is included.

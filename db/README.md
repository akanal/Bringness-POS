# Datenbank

PostgreSQL ist die zentrale Datenbank. Das Schema wird mandantenfähig aufgebaut: Unternehmen -> Restaurants/Filialen -> Geräte/Mitarbeiter -> Kassendaten.

Geplant sind versionierte Migrationen für Kunden, Restaurants, Lizenzen, Geräte, Mitarbeiter/Rollen, Artikel, Kategorien, Varianten, Bestellungen, Zahlungen, Belege, Schichten, TSE, Audit und Synchronisation.

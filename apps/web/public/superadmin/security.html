Zur Anmeldung

Authenticator einrichten

Du brauchst dein aktuelles Passwort und eine Authenticator-App auf deinem Handy. Die Einrichtung wird erst mit deinem ersten gültigen Code aktiviert.

1. QR-Code mit der Authenticator-App scannen

2. Wiederherstellungscodes sicher speichern

Jeder Code ist nur einmal verwendbar. Bewahre sie getrennt von deinem Handy auf. Sie werden nur bei dieser Einrichtung angezeigt.

3. Mit dem Handy-Code bestätigen

Nach der Bestätigung werden deine anderen Sitzungen abgemeldet. Diese Sitzung bleibt bis zu zwölf Stunden angemeldet.

Zwei-Faktor-Anmeldung deaktivieren

Nutze dies zum Wechseln deines Handys oder zum erneuten Einrichten. Nach der Deaktivierung ist vorübergehend nur dein Passwort erforderlich.

Du hast dich gerade mit einem Wiederherstellungscode angemeldet. Innerhalb von fünf Minuten reicht hier dein aktuelles Passwort, damit auch mit dem letzten Ersatzcode eine Neueinrichtung möglich bleibt.
